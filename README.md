## Overview

Chaos Mod V introduces a stream-vote and timer-driven system of random chaos effects to GTA V, triggering one new effect every configurable interval — spawning vehicles, changing weather, reversing controls, exploding all cars, or hundreds of other outcomes. Designed for stream integration via Twitch voting, it turns ordinary GTA V sessions into unpredictably hilarious chaos.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Chaos Mod V** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **300+ Effects** | Over 300 unique chaos effects from harmless to completely game-breaking |
| **Twitch Voting** | Viewers vote for the next effect via Twitch chat during live streams |
| **Timer Control** | Configurable countdown between effects from 15 seconds to several minutes |
| **Effect Categories** | Enable or disable entire categories of effects by severity level |
